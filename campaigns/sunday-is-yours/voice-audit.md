## Open flag — not a campaign asset, but worth raising

`sunday_reset_command_dashboard.html` (uploaded separately, for the related **Sunday ResET** live-training product) uses teal (`#2a9d8f`) as an accent color throughout its CSS. This directly contradicts the OID's brand color rule. It wasn't built as part of this campaign and wasn't edited here, but since it lives in the same brand ecosystem, it should get a color pass before it's used publicly.
