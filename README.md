## NotebookLM ↔ Claude (MCP)

Wiring Google NotebookLM into Claude as an MCP server — 38 tools for notebooks,
sources, chat, research, and Studio artifacts.

See [`notebooklm-mcp/`](./notebooklm-mcp/) for the full setup:

- **Path A** — Claude Code / Desktop, ~10 min: `notebooklm mcp install claude-code`
- **Path B** — claude.ai custom connector (web + mobile), needs a public HTTPS host
