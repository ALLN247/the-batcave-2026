# Rochester Omega Lamplighters — 2026–27 Program System

Year Two operating system for the Rochester Omega Lamplighters, built on the same methodology as the UPrep Golf 2026–27 package: a family-facing guide, a detailed monthly calendar, a director-facing blueprint, and an honest decision register.

**Framework:** LAMP (Leadership · Academics · Maturity · Perseverance) × 18-O "Show Me the Money"
**Pipeline:** Boys 2 Men (9–13) → Rochester Omega Lamplighters (14–18) → Omega Psi Phi

## The Order of Operations

1. **Work the blocking decisions** in `05` — class size, meeting space, budget, session time. Nothing goes to families before these close.
2. **Deliver the recruitment presentation** and collect written volunteer commitments. Class size is sized to the bench, not to demand.
3. **Send the letter and the guide.** Collect signed acknowledgments — including the hours-per-month line.
4. **Run September.** Standard, Creed, tiers, first B2M event, first volunteer ask.
5. **Close out every month in Week 4:** attendance, artifacts, scoreboards, family email, B2M debrief.

---

## Conventions

- `[CONFIRM]` marks a date, contact, venue, or approval that still needs to be locked.
- The decision register in `05` uses 🔴 blocking / 🟡 important / 🟢 strategic / ⚪ verify.
- Conflicts get flagged, never silently resolved.
