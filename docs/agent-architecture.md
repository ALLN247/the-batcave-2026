## Why Three Separate Agents

Each agent failure mode without separation:

| Risk | Cause | Solution |
|---|---|---|
| Agent Collapse | One agent overloaded with thinking + acting + marketing | Separate cognitive, operational, and brand layers |
| Voice Dilution | Marketing mixed with operations | NOVA owns brand voice exclusively |
| Execution Drift | Ideas generated but never coordinated | ATLAS as dedicated coordination layer |
| Thinking Loss | Insights generated but never retained | Scout OS maintains cognitive continuity |

## Design Methodology

All agents follow Scout OS's **Generative Design Protocol**:

1. **Identity** — Name, role, archetype
2. **Mission** — What problem does this agent solve?
3. **Function** — What does it actually do?
4. **Personality** — Voice, style, operating character
5. **Responsibilities** — Full scope of work
6. **Behaviors** — Must do / must never do
7. **Output Structure** — What it produces and in what format
8. **Integration** — How it connects to the rest of the system
9. **Constraints** — What it cannot override
10. **Handoff Protocol** — How it passes work forward
