## Why Two Separate Agents

A single overloaded agent handling note-taking, planning, reflection, execution management, prioritization, and strategic coordination simultaneously creates **agent collapse** — degraded performance across all functions.

The Scout OS / ATLAS split mirrors elite human organizations:
- Scout OS = the analyst / strategist thinking room
- ATLAS = the chief of staff running the operation

Each agent stays in its lane. The founder stays in command.

## Design Methodology

Agent designs follow a structured specification format:
1. System Identity
2. Primary Mission
3. Organizational Context
4. Core Operational Principles
5. Primary Responsibilities
6. Agentic Behaviors
7. Operating Loop (staged sequence)
8. Response Structure
9. Memory Priorities
10. Hard Constraints

This ensures each agent is deployable, consistent, and constrainable.
