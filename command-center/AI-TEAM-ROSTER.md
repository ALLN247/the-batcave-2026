## HOW TO UPDATE THIS ROSTER

When you build a new specialist:
1. Build the Skill File and save it to Google Drive → Brain/Specialists/[skill-name]
2. Add a row to this table: Specialist | What it does | Call it when | File location
3. Upload the updated roster to your AI.G Claude Project knowledge base
4. AI.G will read the updated roster on next session load

**Roster update prompt:**
> "Please review the attached roster template and update the table to remove [SKILLS TO REMOVE] and add [SKILLS TO ADD]."

**Test prompt (from AICC 2.0 training):**
> "Tell me when you hear one of my tasks and the orchestrator goes to pick a specialist from the roster, what are the choices that you would use?"
