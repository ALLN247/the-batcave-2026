1. Open Claude.ai → Projects → your AI.G project
2. Click **Add to project knowledge**

4. Do NOT delete any existing files in the project — this is purely additive
5. Your existing skills, context, voice files, and memory all stay in place

**Where:** Claude Project → Settings → Project Instructions (paste this line at the top or bottom of existing instructions)

This confirms AI.G has read the roster and is routing correctly.

Then try a real task:

You should see: *Routing: Social content → HERALD / SOCIAL CONTENT ENGINE*
