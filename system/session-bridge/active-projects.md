# Active Projects Dashboard
## Coach G / Teach Transformations — The Batcave

**Purpose**: One view of every active project. Scanned in the Sunday System weekly sweep to reset Next Actions and surface anything that's stalled or disconnected from the TOS.

**Update cadence**: Weekly (Sunday System) or whenever a project's status changes.

---

## Sunday Sweep Protocol

Run this every Sunday as part of the Sunday System (EOS — Ch.5):

1. Scan every row below.
2. For any project marked **Paused** or where Last Touched is more than 7 days ago — read its PSF. Make a binary decision: **Reactivate** or **Shelve**.
3. For every **Active** project — confirm the Next Action is still accurate and achievable this week.
4. For anything **Shelved** — leave it. You may return to it when the TOS Decision Engine green-lights it again.

**Key question on every row**: *"Does this project have a PSF with a current Next Action? If not, it doesn't count as active."*
