# Opening Ritual — Session Re-Entry Protocol

*Routing: Focus OS / session start → AI.G*

**When to run**: At the start of any work session on a project you haven't touched in more than 24 hours.
**Time required**: 3 minutes.
**How to use**: Copy the prompt below, paste it to AI.G (or your active AI tool), and attach or paste the PSF for that project.

---

## The Opening Prompt

Paste this to AI.G at the start of a session, with the PSF attached:

---

> **AI.G — Session Opening. Load this project:**
>
> Read the attached Project State File (PSF) and do the following:
>
> 1. **Reorient me** — In 2-3 sentences, tell me where this project is and what it's for. Assume I haven't thought about this in several days.
>
> 2. **Connect it back** — Remind me of the TOS Connection from the PSF. Why does this project exist in my operating system? Which mission layer does it serve?
>
> 3. **Give me one thing** — State the Next Action from the PSF, exactly as written. If the Next Action field is blank or unclear, flag it and suggest the most logical next move based on the Current State.
>
> 4. **Check my motivation** — Read the Motivation Capture section and surface the part that would most likely re-ignite my energy right now.
>
> 5. **Tell me what NOT to do** — Name one thing the PSF suggests I should avoid or defer in this session, so I don't get pulled sideways.
>
> Do not summarize everything in the PSF. Be brief and direct. I want to be working in 3 minutes, not reading for 10.

---

## Without AI (manual version)

If you're not near a chat interface, read just these four fields from the PSF before starting:

1. **TOS Connection** — why does this project exist?
2. **Current state** — where exactly did you stop?
3. **Next Action** — what's the ONE thing?
4. **Motivation Capture** — what excited you about this?

Set a 3-minute timer. Read those four fields only. Then start.

---

## The rule

You do not open a project file until you've run the Opening Ritual. Even if you think you remember where you were — run it. Context Collapse is invisible until you're already lost.
