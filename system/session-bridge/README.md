# The Session Bridge
## Focus OS — Context Collapse Prevention Protocol

**Problem it solves**: Context Collapse — when you return to a project days later and can't reconnect to the work, the context, or the motivation because everything that made it make sense was stored only in your head.

**Root cause**: No external working memory. The project stores the work. It doesn't store your mental state, your current position, or why you were excited. When your head moves on, that context disappears.

**The Session Bridge is three things:**

1. **The Project State File (PSF)** — a living document that sits at the top of every project. It captures where you are, what comes next, and why this matters — written *before* you leave, readable in under 60 seconds when you return.

2. **The Opening Ritual** — a 3-minute re-entry protocol. Run it before you start any session on a project you haven't touched in a while. Gives you back your context without digging through files.

3. **The Closing Ritual** — a 2-minute state capture. Run it before you close any session. Captures what you just did, what comes next, and what you were feeling — while it's fresh.

---

## How it integrates into the TOS

| TOS Layer | How the Session Bridge connects |
|---|---|
| Focus OS (LOS) | The 90-min deep work block starts with the Opening Ritual — no more wasted first 20 minutes trying to remember where you were |
| EOS — Sunday System | Weekly Project Sweep: review all active PSFs, reset Next Actions, park anything that's stalled |
| KOS | PSFs become the living memory layer for every project — THE ALCHEMIST can pull from them to generate summaries, status reports, and handoffs |
| AI.G | AI.G runs both rituals on request — Opening and Closing prompts are the two standard prompts (see files in this folder) |
| LINK | When a PSF's TOS Connection field is blank or weak, flag to LINK for ecosystem evaluation — does this project belong? |

---

## The rule

**Every project gets a PSF. Every session ends with an update. No exceptions.**

A PSF that takes 2 minutes to update at the end of a session saves 20 minutes of disorientation the next time you open the file — and keeps the project from dying in your draft folder.

## Files in this folder

- `PSF-template.md` — copy this into the top of every project folder
- `opening-ritual.md` — the AI.G prompt to run at the start of a session
- `closing-ritual.md` — the AI.G prompt to run before you close a session
- `active-projects.md` — your live Project Dashboard (one row per active project)
